# Run — Çoklu çizgi + video A/B yan + isim + per-line

## İstek
(1) Test videosunda A/B çizginin iki yanında (editörle aynı), (2) 2 çizgi çalışmıyordu → çalışsın, (3) çizgi isimleri çizgi üstünde, (4) analiz rakamları çizgi başına. + soru: client'a exe mi web mi.

## Yapıldı
- ⚡ `count.py` baştan: **çoklu çizgi**. `run_count(lines=[{name,pts}])`; her çizgi ayrı last_side/counted/in/out. `CountResult.lines=[{name,in,out}]`. Annotated videoda her çizgi: A/B **perpendiküler yan** etiketi (editörle aynı) + **çizgi adı** üstte + sol üstte toplam & çizgi-başına döküm. `_ascii()` (Hershey Türkçe basmaz).
- ⚡ `server.py`: `_saved_line`→`_saved_lines` (tüm line zone'lar, isimli) → `run_count(lines=...)`. Özet `count.lines` taşır.
- 💾 `store.py`: `count_events.line_name` (ALTER+try migration); `add_count_event(...,line_name)`; events detail'inde çizgi adı.
- 🎨 `web/index.html`: kart per-line döküm (turuncu nokta + isim + giriş/çıkış); editör canvas'ında çizgi adı çizgi üstünde.

## Doğrulama

## Mimari cevap (exe vs web — client kurulumu)
**Web (sunucu+tarayıcı) standart ve daha mantıklı.** Ağır işlem (YOLO/InsightFace/RTSP) zaten edge kutuda servis/daemon olarak koşar; UI ince istemci. Avantaj: ağdaki her cihazdan (PC/telefon/tablet) kurulum gerektirmeden erişim, çok kullanıcı, tek noktadan güncelleme, cross-platform. Frigate/Genetec/Verkada/Milestone hepsi böyle. Üretim: FastAPI'yi systemd (Linux/Jetson) / Windows service olarak çalıştır, tarayıcı http://kutu-ip:8000. **exe/desktop** sadece tek-makine/tek-operatör veya derin OS entegrasyonu gerekirse; o zaman Electron/Tauri ile web UI'yı sarmalamak (yine altta web). → AurasVision için: edge'de servis + web UI; istenirse masaüstü kısayolu için ince Tauri/Electron sarmalayıcı.
