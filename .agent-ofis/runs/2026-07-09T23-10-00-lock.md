# Run — 2026-07-09 — Zone kaydı kilidi

**Şikâyet:** "Videoda yukarıdan aşağa çizgi var, Bölgeler'de çizgiler doğru çalışmıyor."

## Kök neden zinciri (kanıtlı)
1. Dikey çizgi = kayıtlı çizgi bulunamayınca düşülen **varsayılan orta çizgi** (count.line fallback).
2. Kullanıcının çizgi kaydı `POST /api/zones` → **500 "database is locked"** (server.log traceback: clear_zones→_x).
3. Neden kilit: SQLite bağlantısı default isolation_level ile **ilk olay INSERT'inden analiz sonuna dek tek yazma transaction'ı** tutuyor; Abide analizi dakikalar sürünce 30 sn busy_timeout yetmiyor. (MEMORY'deki "WAL+busy_timeout çözdü" notu eksikmiş — uzun transaction'ı çözmüyordu.)
4. UI ikinci kusur: saveZones 500'ü yutuyordu (api() json parse throw → zstatus güncellenmiyor) — kullanıcı kaydın başarısız olduğunu göremedi.

## Düzeltme (commit ed22e8e)
- `SqliteStore`: `isolation_level=None` (autocommit) — her INSERT kısa kilit; `in_transaction=False` yapısal kanıtı alındı.
- `saveZones`: try/catch + zstatus'a açık hata mesajı.
