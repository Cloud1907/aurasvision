# Run — Bölge editörü UX revizyonu

## İstek
Çizim amatördü: (1) bas-çek ile çiz + sonradan uçlardan düzelt, (2) ✕ ile sil, (3) her çizgiye isim, (4) A ve B çizginin **iki yanında** (uç değil).

## Yapıldı (frontend — web/index.html)
- 🎨 Frontend — editör mouse modeline geçti: `onDown/onMove/onUp`. Çizgi **bas-çek** (mousedown→drag→mouseup, kısa tıklama yok sayılır >0.03). Uç **tutamaçları sürüklenebilir** (hitHandle). **✕ rozeti** (kırmızı, hitX) ile silme. Poligon (bölge/ihlal) tıkla-nokta + "Bölgeyi bitir".
- A/B artık **perpendiküler iki yan etiketi** (uç değil): B = pozitif taraf = count "in" yönü → A→B giriş. Ortada yön oku.
- **İsimlendirme**: her çizim listede isim kutusu (`renderZoneList`, `renameZone`), varsayılan "Çizgi N / Bölge N / İhlal N"; satır başında ✕ sil.
