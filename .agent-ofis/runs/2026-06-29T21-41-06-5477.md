# Run — A→B çizgi + UI'dan test çalıştırma

## İstek
"çizgi A'dan B'ye olmalı, geçişleri sayalım" + "arayüzden video oynatıp sayım/plaka test edeyim".

## Yapıldı
- ⚡ Backend — `count.py`: `line_override` param (kayıtlı normalize A→B çizgisi). A→B='in', B→A='out'. Annotated videoda A/B uçları + yön etiketi.
- ⚡ Backend — `server.py`: `POST /api/run {camera,kind}` → kayıtlı çizgiyi `_saved_line()` ile çeker, analizi save_video=True çalıştırır, DB'ye yazar, summary+video URL döndürür. `/media` mount ile annotated videolar servis edilir.
- 🎨 Frontend — `web/index.html`: editör çizgisinde **A/B etiket + yön oku ("A→B giriş")**; yeni **Test ekranı** (kamera seç · Sayım/Plaka/Yüz/Hepsi · Çalıştır · özet kartları · `<video>` oynatıcı).
- 🔍 QA — /api/run count (giris, kayıtlı çizgi) → in:1 out:1, 6.5sn; /media video 200; UI screenshot: Test ekranı (sonuç+player) + editör A/B doğrulandı.

## Doğrulama
